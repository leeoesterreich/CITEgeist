## Success Criteria

| Metric | Target | Rationale |
|--------|--------|-----------|
| **Functionality** | All 3 sources complete without errors | Code works on both resolutions |
| **Gene concordance** | Jaccard > 0.3 for matched programs | Top genes overlap meaningfully |
| **Spatial concordance** | Pearson r > 0.5 for activity patterns | Spatial structure preserved |
| **Cross-region conservation** | >50% programs conserved across regions | Module 5 finds consistent biology |

## Failure Modes

- **Single-cell programs don't match deconvolved** → Deconvolution losing biological signal
- **Manual vs autodiscovery diverge significantly** → Profile discovery issue
- **Low cross-region conservation** → Programs are noise, not reproducible biology
