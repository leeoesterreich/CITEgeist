## Problem Statement

The v4 manuscript was generated by an agent revision process that introduced several categories of error:

1. **Factual errors**: "immunotherapy" used instead of "endocrine therapy"; "neoadjuvant therapy" instead of "primary endocrine therapy (aromatase inhibitors)"
2. **Missing clinical nuance**: No explanation of responder/progressor timelines, no mention that responders' surgery was incidental (~18 months), progressors showed progression (~36 months). Replicate samples not addressed.
3. **Gutted midkine results**: v3 had a full results section on MDK signaling discovery with wet lab validation (ELISA, immunofluorescence). v4 reduced this to a single passing reference.
4. **Fabricated acknowledgments**: v4 lists funding sources (Breast Cancer Research Foundation, Nicole Meloche Foundation, Susan G. Komen) not present in v3. Must replace with v3 content.
5. **Wrong author list/affiliations**: Missing Hunter Waltermire, reduced from 7 to 3 affiliations, "McAuliffe" misspelled as "McAulife", missing co-first authorship notation.
6. **AI writing style**: Bullet-heavy, listy prose that reads as agent-generated. Needs natural academic flow.
7. **Wrong journal format**: Current format doesn't match CRM requirements (missing Motivation section, Limitations section, STAR Methods structure, Key Resources Table, Highlights, eTOC blurb).
8. **Wrong citation style**: Currently uses bracket numbers; CRM/Patterns use numbered superscript.
