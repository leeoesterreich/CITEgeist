Notebooks
=========

Full vignette notebooks (patient cohort data) are not included in this public release
due to private data paths. To get started, use the runnable example scripts and
narrative documentation instead:

* :doc:`quickstart` — minimal working example
* :doc:`tutorial` — step-by-step workflow guide
* :doc:`examples` — complete analysis patterns and parameter tuning

Example scripts covering the core workflow are available in the ``examples/scripts/``
directory of the repository.
